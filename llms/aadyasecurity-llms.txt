## What this company publishes

AaDya Security / Judy Security publishes **no public API, no developer portal, no
API reference and no machine-readable API contract**. As of 2026-09-05 there is no
OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC/Protobuf, WSDL, MCP server or A2A agent
card served on any host this company controls. Do not attempt to call a Judy
Security API; there is not a documented one.

The product's own backend hosts (login.judysecurity.ai, edge.judysecurity.ai,
dns.judysecurity.ai) are private application endpoints for the Judy agents and the
Judy Control Center. They are undocumented, unversioned and not offered for
third-party integration.

## Product

Judy is a single-platform bundle for SMBs, delivered through channel partners:

- Endpoint detection and response (Windows and macOS agents)
- DNS filtering
- Password manager
- Cloud SIEM + XDR ("Blue Team")
- Automated compliance management and reporting
- Secure and passwordless authentication
- Security awareness training
- Judy Control Center (unified management, reporting and dashboards)

## The documented API surface is outbound only

The only API documentation the company publishes describes configuring Judy to push
support tickets **into** third-party PSA systems using those vendors' APIs:

- ConnectWise PSA integration setup: https://www.judysecurity.ai/guides/judy-security---connectwise-api-integration-setup-guide
- Datto Autotask PSA integration setup: https://www.judysecurity.ai/guides/judy-security-autotask-api-integration-setup-guide

Both guides cover credentials and permissions in the *partner's* system. Neither
documents a Judy Security endpoint.
